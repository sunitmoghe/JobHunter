# 🌍 JobHunter AI

An AI-powered Executive Career Platform designed for senior professionals to discover global opportunities, optimise resumes, improve ATS scores, and manage the complete job search process.

---

## 🚀 Current Features

- Resume PDF Parser
- ATS Resume Matcher
- Resume Intelligence
- Executive Skills Database
- Streamlit Dashboard
- SQLite Database
- GitHub Version Control

---

## 🛠 Technology Stack

- Python 3.x
- Streamlit
- SQLite
- Plotly
- Pandas
- Git & GitHub
